## 기능

### 반드시 만드는 것

| 기능 | 어떻게 동작하나? |
|---|---|
| **기계 목록** | 세탁기 8호기 · 건조기 4호기가 한 화면에. 상태는 **사용가능 · 사용중 · 고장** 세 가지이고, 사용중인 기기는 남은 시간과 진행 막대가 함께 보인다. 전체 / 세탁기 / 건조기로 걸러 보며, 위쪽에는 기종별로 전체 몇 대 중 몇 대가 비었는지 요약 막대가 뜬다 |
| **원격 줄서기** | 방에서 **기종 단위로** 줄을 선다. 빈 기기가 있으면 즉시 배정되고, 없으면 **가장 먼저 끝나는 기기**로 자동 배정된다 — 호기는 지정할 수 없다. 지금 몇 명이 기다리는지와 배정까지 남은 시간이 홈에 보인다. 세탁기와 건조기에 각각 한 줄씩 최대 두 줄까지. 줄 빠지기는 언제든 가능하고, 같은 기기는 15초 뒤에 다시 신청할 수 있으며 다시 설 때는 맨 뒤부터다 |
| **QR로 사용 시작 (고정 타이머)** | 안내 창("세탁물을 넣은 뒤 기기에 붙은 QR을 찍어주세요") → QR 스캐너 → 인식 완료 순서. **코스를 고르지 않고** 타이머가 바로 돈다. **세탁기 60분 · 건조기 45분 고정**. QR이 찢어지거나 오염돼 인식되지 않으면 신고하기에서 "기기가 고장났어요"로 접수하고, 배정 후 10분이 지나기 전에 접수하면 경고가 부여되지 않는다 |
| **"다 했어요"** | 남은 시간과 관계없이 이용이 끝나고 기기는 곧바로 **사용가능**, 다음 대기자에게 바로 배정된다. 일찍 끝났을 때만 누르는 버튼이 아니라 **끝날 때마다 항상** 누르는 버튼이다. 타이머가 0이 되면 카드가 붉게 바뀌며 "시간이 끝났어요! 지금 누르지 않으면 경고가 쌓여요"가 뜨고, **3분** 안에 누르지 않으면 경고 1회가 쌓이면서 기기는 자동으로 풀린다 |
| **끝나는 시간 주의 문구** | 고정 타이머와 실제 종료 시각이 어긋날 수 있다는 안내를 넣을지 정해야 한다 |
| **10분 전 알림** | 지금 있는 것은 **내 차례가 오기 10분 전** 알림이다 — 설정의 "차례 10분 전 알림"으로 끄고 켠다. **내 빨래가 끝나기 10분 전** 알림은 아직 없다 |
| **종료 알림** | 알림의 **종료** 갈래로 온다 — "세탁기 3호기 사용이 끝났어요 / 시간 안에 세탁물을 수거해주세요" |
| **다음 사람 10분 여유시간** | 배정된 순간부터 **10분**. "○○호기 차례가 됐어요! 10분 안에 QR을 찍어 시작해주세요"가 뜨고, 홈의 현재 상태 카드에서 남은 시간이 초 단위로 줄어든다. 10분이 지나면 "인증 시간 초과" 안내 창과 함께 다음 대기자에게 넘어가고, **넘긴 사람에게 경고 1회**가 쌓인다 |
| **3분 초과 · 경고** | "아직 안 빼갔어요" 버튼은 없다. 대신 두 갈래로 나뉜다 — ① 타이머가 끝나고 **3분**이 지나도록 "다했어요"를 누르지 않으면 자동으로 경고 1회. ② 앞사람 세탁물이 남아 있으면 대기자가 **신고하기 → "세탁물이 있어요"** 로 기종 · 호기와 사진을 붙여 접수하고(선택사항), 관리자가 확인하면 앞사람에게 경고가 부여된다. 꺼내도 된다는 안내는 아직 없다 |
| **경고 3회 = 3일 정지** | 경고 3회면 **3일** 동안 줄서기가 막힌다. 줄서기 버튼이 "이용 제한 중"으로 잠기고 남은 기간이 함께 뜬다. 경고는 ① 배정 후 10분 안에 미사용 ② "다했어요" 미클릭 ③ 종료 후 3분 내 미수거 ④ 차례가 아닌데 사용(신고 확인 시) 네 가지로 붙고, ②와 ③이 함께 일어나면 통합 1회만 부여된다. 경고는 매달 1일에 0회로 초기화되지만 이미 시작된 3일 제한은 기간을 다 채워야 풀린다 |
