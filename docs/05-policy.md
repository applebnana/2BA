## 상태값
사용 가능 → **배정**(대기 1번에게 10분) → 사용 중(세탁 60분 · 건조 45분) → **수거 대기**(타이머 0 후 3분) → 사용 가능
별도 상태: **고장**(관리자 처리) · **점검 중**(세탁실 전체)
=======
| P1 (판정 필요) | QR 사용 시작 | A1(모든 사생) | 기계 상태 = 비어있음 | QR을 찍은 사람만 사용을 시작할 수 있다고 가정한다 — QR 없이 쓰는 것은 앱이 막을 방법이 없어 제약으로만 둔다 | 해당 없음 — 앱 밖 행동이라 위반을 표시할 방법이 없음 |
| P2 | 다음 사람 여유시간 | A1(대기 1번) | 기계 상태 = 종료추정(앞사람 종료 시점부터) | 10분 안에 QR을 찍어 사용을 시작해야 한다 | 10분을 넘기면 자동으로 다음 대기자에게 순번이 넘어간다. 단 다음 사람이 아직 QR을 안 찍었으면 원래 사람이 그대로 쓸 수 있다 |
| P3 | 방치 경고 | A1(세탁물 주인) | 기계 상태 = 종료추정, 대기자가 "아직 안 빼갔어요"를 누른 시점부터 | 3분 안에 세탁물을 빼가야 한다 | 대기자 화면에 "꺼내도 좋습니다"가 뜨고, 주인에게 경고 1회가 쌓인다 |
| P4 | 경고 누적 정지 | A1(경고 3회 누적자) | 경고 횟수 = 3회 | 3일간 QR 사용 등록 · 원격 줄서기를 할 수 없다 | [?] 정지 중 접근 시 화면에 무엇을 보여줄지("n일 후 해제" 등) 미정 |
