# 정책 정의서 — 세탁기 및 건조기 원격 줄서기

## 정책
| P | 대상 F | 누가 | 언제(상태값) | 규칙 (할 수 없다 · 까지) | 위반 시 앱이 보이는 것 |
|---|---|---|---|---|---|
| P1 | 다음 사람 10분 여유시간 | 배정받은 대기 1번 | 배정 시점(빈 기기 발생 또는 앞사람 "다했어요")부터 · **배정** | 10분 안에 QR을 찍어야 한다. 넘기면 순번이 다음 대기자에게 넘어간다 | 배정 알림 "10분 안에 시작하지 않으면 다음 사람에게 넘어가요" · 카드에 남은 시간 초 단위 표시 · 10분 경과 시 안내 창 "인증 시간이 초과되어 다음 대기자에게 순서가 넘어갑니다. 이용을 원하실 경우 다시 줄서기해주세요" · **경고 1회** |
| P2 | "다했어요" 미클릭 | 이용자 | 타이머 0 시점부터 · **수거 대기** | 3분 안에 "다했어요"를 눌러야 한다 | 카드가 붉게 바뀌며 "시간이 끝났어요! 지금 누르지 않으면 경고가 쌓여요" · 3분 경과 시 "시간 내 '다했어요'를 누르지 않아 경고가 1회 누적됐어요" · **경고 1회** · 기기는 자동으로 사용가능 전환 |
| P3 | 세탁물 미수거 | 세탁물 주인 | 타이머 0 시점부터 · **수거 대기** | 3분 안에 세탁물을 빼가야 한다 | 대기자가 신고하기 → "세탁물이 있어요"로 접수 → 관리자 확인 시 **경고 1회** · 신고자에게 "접수하신 신고가 처리가 완료됐어요" |
| P4 | 순서 미준수 | 차례가 아닌 사용자 | 배정받지 않고 기기를 쓴 때 | 자기 차례가 아닌 기기를 쓸 수 없다 | 다른 사용자가 신고하기 → "순서를 지키지 않았어요" → 관리자 확인 시 **경고 1회** |
| P5 | 경고 3회 = 3일 정지 | 경고 누적자 | 경고 3회 누적 시 | 3일간 원격 줄서기를 할 수 없다 | 홈 줄서기 버튼이 "이용 제한 중"으로 잠김 · "경고 누적으로 N일 동안 이용이 제한돼요" · 기록 화면 "이용 제한 중 · N일 남음" |
| P6 | 경고 중복 방지 | 경고 판정 | P2와 P3이 함께 발생한 때 | 두 건을 각각 세지 않는다 | 통합 **1회**만 부여 |
| P7 | 경고 초기화 | 경고 누적자 | 매달 1일 | — | 0회로 초기화. 이미 시작된 3일 제한은 초기화와 관계없이 기간을 모두 채워야 해제된다 |
| P8 | QR 미인식 면책 | 배정받은 대기 1번 | 배정 후 10분 안 | QR이 찢어지거나 오염된 경우 신고하기 → "기기가 고장났어요"로 접수해야 한다 | 10분이 지나기 전에 접수하면 P1의 경고가 부여되지 않는다 |
| P9 | 줄 개수 제한 | 모든 사용자 | 줄서기 시도 시 | 세탁기 1줄 · 건조기 1줄, 합쳐 두 줄까지. 같은 기종에 중복으로 설 수 없다 | "이미 세탁기 대기열에 참여 중이에요" |
| P10 | 재신청 제한 | 줄에서 빠진 사용자 | 줄 빠지기 직후 | 15초 안에 같은 기기에 다시 신청할 수 없고, 다시 설 때는 맨 뒤부터다 | 버튼이 "대기중"으로 잠김 · "대기열에서 나갔어요. 잠시 후 다시 신청할 수 있어요" |
| P11 | 배정 포기 | 배정받은 대기 1번 | **배정** 상태에서 줄 빠지기 | 배정 상태에서 빠지면 그 기기는 곧바로 다음 사람에게 넘어간다 | 순번이 즉시 이전됨 |
| P12 | 호기 지정 불가 | 모든 사용자 | 줄서기 시 | 특정 호기를 고를 수 없다. 같은 기종 중 가장 먼저 비는 기기로 자동 배정된다 | "대기열에 참여했어요. 먼저 끝나는 기기로 자동 배정돼요" |
| P13 | 점검 중 차단 | 모든 사용자 | 관리자가 점검 모드를 켠 동안 | 줄서기를 할 수 없다 | 버튼이 "점검 중"으로 잠김 · "세탁실 점검 중이라 잠시 이용할 수 없어요" |
| P14 | 고장 기기 제외 | 시스템 | 관리자가 고장 처리한 동안 | 해당 기기는 배정 대상에서 빠진다 | 목록에 **고장** 표시 · 배정 후보에서 제외 |
| P15 | 관리자 판정 | 관리자 | 신고 접수 후 | 신고를 접수됨 → 처리중 → 처리완료로 넘기거나 반려한다. 경고를 직접 부여·차감할 수 있다 | 반려 시 신고자에게 "사실이 아닌 것으로 확인되어 반려됐어요" · 부여·차감 내역은 기록 화면에 남는다 |
| P16 | 경고 기록 단위 | 시스템 | 경고 부여 시 | 경고는 호실이 아니라 **사용자 단위**로 기록한다. 실제 서비스에서는 학번·이메일을 키로 쓴다 | 같은 호실이어도 사람별로 따로 쌓인다 |

## 상태값
사용 가능 → **배정**(대기 1번에게 10분) → 사용 중(세탁 60분 · 건조 45분) → **수거 대기**(타이머 0 후 3분) → 사용 가능
별도 상태: **고장**(관리자 처리) · **점검 중**(세탁실 전체)

## 서비스 정책
| SP | 한 줄 |
|---|---|
| SP1 | 세탁기·건조기 전원 자체는 막지 못한다 — 막을 수 있는 건 우리 사이트의 QR 사용 등록 · 원격 줄서기까지다 |
| SP2 | 세탁·건조 시간은 코스별로 재지 않고 세탁기 60분 · 건조기 45분으로 고정한다 |
| SP3 | 기기 상태는 앱에 등록된 것만 안다. QR을 찍지 않고 쓰면 앱에는 사용가능으로 남는다 |
| SP4 | 사람이 판단해야 하는 위반(세탁물 미수거 · 순서 미준수)은 자동 판정하지 않고 신고 → 관리자 확인을 거친다 |
| SP5 | 앱은 남의 세탁물을 꺼내도 된다고 허가하지 않는다. 분실·훼손 위험을 안내할 뿐이다 |
| SP6 | 가입은 학교 이메일(ac.kr) 인증을 거친다. 사생이 아닌 사람은 쓸 수 없다 |
| SP7 | 제재 수단은 줄서기 제한 하나다. 이미 시작한 세탁을 중단시키지 않는다 |

## 확인이 필요한 것
- **P1의 경고 부여** — 초안에는 순번 이전만 있었는데 디자인은 경고까지 준다. 배정을 놓친 것과 세탁물을 방치한 것을 같은 무게로 볼지
- **대기자가 남의 세탁물을 꺼내도 되는 기준(R6)** — SP5로 미뤄둔 상태. "꺼내도 좋습니다" 안내를 만들지 결정해야 한다
- **"대상 F" 열** — 04-features.md에 F 번호가 아직 없어 기능 이름으로 대신 적음
