## 4요소

| 칸 | 내용 |
|---|---|
| **문제** | 기숙사 학생이 세탁기·건조기를 쓰려고 1층에 내려가도 이미 다 사용 중이거나 빨래 바구니로 암묵적 예약이 걸려 있어 바로 못 쓰고, 얼마나 기다려야 하는지 몰라 여러 번 오가야 한다. 세탁물을 바로 빼지 않으면 주인이 나타날 때까지 무한정 기다려야 하고, 세탁기가 고장 나도 바로 고쳐지지 않아 계속 헛걸음한다 |
| **대상** | 기숙사 거주 학생 (세탁기 8대 · 건조기 4대, 1층에 몰려 있음) |
| **현재해법** | 직접 여러 번 1층까지 내려가서 눈으로 확인, 거의 다 된 세탁기 앞에서 기다림, 빨래 바구니를 돌아가는 세탁기 위에 올려 "다음은 나" 암묵적으로 표시 |
| **불편** | 몇 번이고 오가야 하는 번거로움과 언제 끝날지 몰라 답답함 (오가는 횟수 · 시간은 짐작 — 물어볼 것), 세탁물을 안 빼서 주인 나타날 때까지 무한 대기, 세탁기가 고장 나도 바로 고쳐지지 않고 방치됨 |

## 한 문단으로

기숙사 거주 학생은 세탁기 8대 · 건조기 4대가 1층에 몰려 있는 환경에서, 직접 내려가 눈으로 확인하거나 거의 다 된 세탁기 앞에서 기다리는 방식으로 세탁기·건조기를 쓰는데, 이미 다 사용 중이거나 빨래 바구니로 암묵적 예약이 걸려 있어 바로 못 쓰는 경우가 많고, 얼마나 기다려야 하는지 몰라 여러 번 오가야 하며, 세탁물을 바로 빼지 않는 사람 때문에 주인이 나타날 때까지 무한정 기다리기도 하고, 세탁기가 고장 나도 바로 고쳐지지 않아 헛걸음이 반복된다.
