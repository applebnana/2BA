## 4요소

| 칸 | 내용 |
|---|---|
| **문제** | 기숙사 사생이 빨래 바구니를 들고 세탁실에 내려가야만 **빈 기계가 있는지, 몇 명이 기다리는지 알 수 있다**. 다 차 있으면 방으로 되돌아왔다가 다시 내려간다 |
| **대상** | 세탁실 하나를 함께 쓰는 **기숙사 사생** (한 동 약 200명 · 세탁기 8대 · 건조기 4대) <!-- FACT:data 대수 · 인원은 우리 기숙사에서 직접 세어 확인 --> |
| **현재해법** | 일단 내려가서 눈으로 본다 · 끝날 시간을 기억해 뒀다가 다시 내려간다 |
| **불편** | 저녁 8~11시에 몰려서 **헛걸음을 하루 2번** 한다. 기다리는 사람이 몇 명인지 아무도 몰라 **두 명이 동시에 내려와 먼저 온 사람이 이긴다**. 다 끝난 빨래를 주인이 안 빼가서 **20~30분** 기계가 멈춘 채 묶여 있고, 다음 사람은 그 세탁물을 꺼내도 되는지 몰라 기다린다 (2번 · 20~30분은 짐작 — 물어볼 것) |

## 한 문단으로

세탁실 하나를 200명이 함께 쓰는 기숙사 사생은 빈 기계가 있는지 알려면 빨래 바구니를 들고 직접 내려가 보는 수밖에 없어서 저녁 시간대에 하루 두 번씩 헛걸음을 하고, 몇 명이 기다리는지도 알 수 없어 두 사람이 같은 기계를 노리고 동시에 내려오며, 다 끝난 빨래를 주인이 안 빼가면 기계가 멈춘 채 20~30분 묶여 있는데 다음 사람은 남의 세탁물을 꺼내도 되는지 몰라 그냥 기다린다.

## 기능

### 반드시 만드는 것

| 기능 | 어떻게 동작하나 |
|---|---|
| **기계 목록** | 세탁기 8대 · 건조기 4대가 각각 어떤 상태인지 한 화면에 |
| **원격 줄서기** | 방에서 대기 줄에 이름을 올린다. 지금 몇 명이 기다리는지 · 내가 몇 번째인지 모두가 본다 |
| **QR로 사용 시작 (고정 타이머)** | 기계에 붙은 QR을 찍으면 **코스를 고르지 않고** 타이머가 바로 돈다. **세탁기 60분 · 건조기 45분 고정** |
| **"다 했어요" (조기 종료)** | 실제로 더 빨리 끝났으면 쓴 사람이 누른다 → 타이머가 즉시 0이 되고 기계는 **비어 있음**, 대기 1번에게 차례 알림이 간다 |
| **끝나는 시간 주의 문구** | 기계 화면 · 남은 시간 · 알림에 항상 붙는다 — **"빨래가 끝나는 시간이 유동적이니 끝나는 시간을 주의해주세요"** |
| **10분 전 알림** | 타이머 기준 끝나기 10분 전 (세탁기 50분 · 건조기 35분 지점) "빨래가 거의 다 됐어요. 가져갈 준비하세요!" |
| **종료 알림** | 타이머가 0이 되면 "빨래가 완료됐어요" |
| **다음 사람 10분 여유시간** | 앞사람이 끝난 시점(타이머가 0이 되고나서 3분 경고 시간 이후 또는 "다 했어요"버튼 클릭)부터 대기 1번에게 **10분**이 주어진다. 해당 시간 안에 세탁을 시작하지 않고 10분이 넘어가면, 자동으로 다음 사람에게 넘어간다 |
| **3분 초과 · 경고** | 지정된 타이머 시간이 전부 다 지났는데도 만약 주인이 세탁물을 안 가져가서 **다 했어요** 버튼을 클릭하지 못했을 때, 3분이 지나면 대기자에게 **꺼내도 좋습니다**가 뜨고, 주인에게 **경고 1회**가 쌓인다 |
| **경고 3회 = 3일 정지** | 경고가 3회 쌓이면 3일 동안 QR 사용 · 원격 줄서기가 막힌다 |

### 안 하는 것

세탁기와의 직접 연동 · 결제 · 고장 신고 · **코스별로 시간을 다르게 재는 것**(전부 고정 시간) · 휴대폰 푸시 알림(시간이 남으면 붙인다)

### 시간 흐름 한눈에 (세탁기 기준 · 건조기는 60→45분만 바뀜)

| 시점 | 쓰는 사람 화면 | 대기 1번 화면 |
|---|---|---|
| QR 찍음 (0분) | "사용 중 · 약 60분 남음 / 끝나는 시간은 유동적입니다" | "내 앞 1명 · 약 60분 뒤" |
| 50분 | "10분 남았어요. 가져가세요" | — |
| 60분 (타이머 0) | "다 됐어요" | **잠시만 기다려주세요** |

| 타이머 3분이 지난 후 10분 | - | **"차례입니다 · 10분 안에 오세요 안 오면 다음 사람에게 넘어감"** |
| 조기 종료 버튼 | "다 했어요" 누름 → 즉시 비어 있음 | 그 시점부터 10분 여유시간 시작 |

## 만들면서 걸린 것 · 어떻게 풀었나

### 1. 첫 번째 사람이 QR을 찍을까

QR을 찍은 사람만이 세탁기를 사용할 수 있다고 가정한다. (제약으로 둔다)

### 2. 타이머와 실제 세탁기 시간이 어긋나지 않을까

**반드시 어긋난다.** 세탁기가 세탁물 무게 · 급수 상태에 따라 시간을 도중에 늘리고, QR 찍는 시점과 시작 버튼 누르는 시점도 다르다. 코스마다 시간이 다른 것도 우리가 알 방법이 없다.

그래서 **맞추려 하지 않는다.** 대신 세 가지로 감당한다.

1. **시간을 고정한다.** 세탁기 60분 · 건조기 45분. 코스를 고르게 하지 않는다. 어차피 정확할 수 없는 값을 정확한 척 입력받는 것이 더 나쁘다. 고정값은 "대충 이 정도 뒤"를 모두가 같은 기준으로 보게 하는 **기준선**일 뿐이다.
2. **빨리 끝나면 사람이 줄인다.** 실제로 40분 만에 끝났으면 쓴 사람이 **"다 했어요"**를 눌러 타이머를 끝낸다. 기계가 못 알려주는 것을 그 자리에 있는 사람이 알려주는 구조다. 누르면 20분이 통째로 다음 사람에게 돌아간다.
3. **틀릴 수 있다고 미리 말한다.** 남은 시간 옆에 항상 **"빨래가 끝나는 시간이 유동적이니 끝나는 시간을 주의해주세요"**를 붙인다. 이 문구가 있어야 "60분이라며?"가 시비가 아니라 예상된 오차가 된다.

**타이머는 경고를 판정하지 않는다.**

| 상태 | 언제 | 화면에 |
|---|---|---|
| 사용 중 | QR 찍음 | "약 20분 남음 (끝나는 시간 유동적)" |
| **종료 추정** | 타이머 0 | "세탁이 완료됐어요" |
| 비어 있음 | 주인이 "다 했어요" 버튼을 클릭했거나 애초에 비워져있을 때 | "사용 가능" |

경고 3분은 지정된 타이머 시간이 다 되고, 다음 대기자에게 부여된 10분 동안 만약 세탁 주인이 세탁물을 가져가지 않았을시 경고 1회가 부여된다. 

### 3. 10분 여유시간이 다른 규칙과 겹치지 않나

겹치지 않는다. 그래서 **재는 타임을 나눈다.**

| 시계 | 누구 것 | 언제부터 | 넘기면 |
|---|---|---|---|
| **10분 여유시간** | 다음 사람 | 앞사람 종료 시점 | 순번이 다음 사람에게 |
| **3분 방치 경고** | 앞사람(주인) | 세탁물 주인이 타이머가 다 되었는데도 세탁물을 안 가져가고 다 했어요 버튼을 누르지 않았을 때 | 경고 1회 + 대기자가 꺼내도 됨 |

### 4. 알림이 정확히 갈까

**전부 도달하지는 않는다.** 웹에서 휴대폰 푸시는 아이폰이면 홈 화면에 추가한 뒤에만 되고, 안드로이드도 권한을 거부하면 끝이다. <!-- FACT:data 팀원 폰 4~5대로 직접 테스트해 확인 -->

그래서 **알림이 안 가도 굴러가게** 만든다. 알림은 보너스고, 진짜 정보는 **사이트를 열면 언제든 보이는 남은 시간과 내 순번**이다. 안 빼간 빨래도 알림이 아니라 **대기자의 "아직 안 빼갔어요" 버튼**이 해결한다 — 주인이 알림을 못 받았어도 대기자는 꺼낼 수 있다.

다만 **10분 여유시간은 알림에 기대는 유일한 규칙**이라 위험하다. 알림을 못 받아 10분을 놓치고 순번이 넘어가면 억울하다. 그래서 **10분이 지났어도 다음 사람이 아직 QR을 안 찍었으면 원래 사람이 그대로 쓸 수 있게** 한다. 순번을 뺏는 게 아니라 **비켜 주는 것**이다. 첫날 알림 도달 테스트 결과는 발표에 숨기지 말고 **측정 항목으로** 넣는다.


### 경고 · 정지가 실제로 막는 것

세탁기 전원은 못 막는다. **막히는 것은 우리 사이트에서의 원격 줄서기까지**다. 이 선을 넘는 것처럼 쓰지 않는다.
