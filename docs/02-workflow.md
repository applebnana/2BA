## 행위자

| A | 이름 | 역할 | 한 줄 상황 | 지금 쓰는 도구 |
|---|---|---|---|---|
| A1 | 기숙사생(빨래 주인) | 사용 당사자. QR을 찍어 타이머를 시작하고, **"다 했어요"를 누를 수 있는 유일한 사람**. 방치하면 경고 1회를 받는 쪽도 이 사람 | 세탁기를 돌려놓고 방으로 올라가, 언제 끝났는지 모른 채 20~30분 뒤에 내려온다 | 일단 내려가서 눈으로 보기 · 끝날 시간을 기억해 뒀다가 다시 내려가기 |
| A2 | 대기자 | 대기 당사자. 줄에 이름을 올리고 순번을 확인하며, 차례가 오면 10분 안에 내려와 QR을 찍는다. 앞사람이 세탁물을 안 꺼냈으면 직접 꺼내고 자기 빨래를 넣는다 — 분실 책임은 꺼내지 않은 주인에게 있다 | 빨래 바구니를 들고 내려갔더니 세탁기가 8대 모두 돌아가고 있어서, 방으로 되돌아왔다가 다시 내려간다. 몇 명이 기다리는지 몰라 다른 사람과 동시에 내려와 먼저 온 쪽이 이긴다 | 일단 내려가서 눈으로 보기 · 끝날 시간을 기억해 뒀다가 다시 내려가기 |

**A1과 A2는 같은 사람이 시간대만 다르게 맡는 역할이다.**

## 단계 (As-Is → To-Be)

### S3 진입 조건

- 차례가 오고 **10분 안에 세탁을 해야한다.** 도착하지 않으면 그 다음 대기자에게 넘어간다
- **원격 줄서기가 순서를 정하는 유일한 방법이다.** 줄에 없는 사람은 세탁실에 먼저 도착해도 순서를 얻지 못한다

### S6 분기

| 내려와서 본 것 | 하는 것 | 결과 |
|---|---|---|
| 기계가 비어 있다 | QR 촬영 | S3으로 — A2가 A1이 된다 |
| 세탁물이 그대로 있다 | 타이머 종료 후 3분이 지났으므로 그냥 꺼낸다 | 주인에게는 경고 1회가 이미 찍혀 있다 |

**"다 했어요"는 세탁물 주인만 누른다.** A2는 이 버튼을 쓰지 않는다. 주인이 타이머가 종료 후 3분 안에 안 눌렀으면 경고가 찍히고 기계는 자동으로 비어 있음이 되므로, A2는 꺼내고 세탁기를 사용하고 타이머를 시작하면 된다.

**꺼낸 세탁물의 분실은 주인이 감수한다.** 3분 안에 가져가지 않은 책임이 주인에게 있다는 것을 규칙으로 명시한다.

### 시간 흐름 (세탁기 60분 · 건조기 45분 · 동일 흐름)

| 시점 | A1 (주인) | A2 (대기 1번) |
|---|---|---|
| 세탁 50분 / 건조 35분 | "10분 남았어요" 알림 | — |
| 타이머 0 | "다 됐어요" 알림 | **"차례입니다 · 10분 안에 오세요"** |
| 0~3분 | **3분 기회 시간** — "다 했어요"를 누르면 경고 없음 | 내려오는 중 |
| 3분 | 안 눌렀으면 **경고 1회** · 기계는 비어 있음으로 전환 | 세탁물을 대기자가 꺼내도 된다 |
| 10분 | — | 안 오면 그 다음 대기자에게 |

3분 기회 시간은 A2의 10분 여유시간 안에 포함되지 않는다.
**대기자가 없어도 3분 기회 시간과 경고는 동일하게 적용된다.**

## 흐름

```
S1 확인 → S2 대기 → S3 시작 → S4 부재 → S5 꺼내기 →「다 했어요」→ 비어 있음
                       ↑                                              │
                       │                                    (10분 알림)│
                       └──────────── S6 인수 ←───────────────────────┘
                                       │
                              (10분 안에 안 옴)
                                       ↓
                                 그 다음 대기자
```

- **정상** A1이 세탁물을 꺼내고 "다 했어요"를 누른다 → 기계가 비어 있음이 되고 대기 1번에게 10분 알림이 간다
- **조기 종료** 타이머보다 빨리 끝났으면 세탁물을 꺼낸 뒤 "다 했어요" 버튼을 클릭하고 순서를 다음 사람에게 넘긴다
- **방치** 타이머 0부터 3분 안에 "다 했어요"를 안 누르면 경고 1회 + 기계 자동 전환. A2는 세탁물을 꺼내고 자기 빨래를 넣는다. 꺼낸 세탁물의 분실은 주인이 감수한다 — 경고 3회면 3일 정지
- **유실** A2가 10분 안에 도착하지 않을 시 그 다음 대기자에게 순번이 넘어감
- **대기자 없음** 3분 기회 시간과 경고는 그대로 적용된다. 넘길 사람이 없으면 기계만 비어 있음이 된다
- **건조기** 45분 기준으로 위 흐름을 그대로 따른다. 알림 시점만 35분 · 45분으로 바뀐다
- **순환** S6 → S3에서 A2가 A1이 되고, 그 사이 새로운 A2가 S1~S2를 돌고 있다

## 열린 질문 [?]

- **고정 시간보다 실제 세탁 시간이 더 긴 경우** — 고정 60분 · 45분은 표준 코스보다 길게 잡아 조기 종료를 막았다. 그보다 긴 코스가 존재하면 타이머 0에 경고가 찍히고 A2도 꺼낼 수 없다. 해결 방법은 별도 논의 예정



### 닫힌 것

- **분실 책임** — 꺼내지 않은 주인이 감수한다
- **건조기** — 세탁기와 동일한 흐름 (45분 기준)
