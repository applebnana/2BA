> 기호: **S** = As-Is 단계(지금 사람이 겪는 순서) · **T** = To-Be 상태(앱 도입 후) · 둘은 번호를 공유하지 않는다

## 행위자

| A | 이름 | 역할 | 한 줄 상황 | 지금 쓰는 도구 |
|---|---|---|---|---|
| A1 | 주인 | 기숙사생 · 지금 기계를 쓰고 있는 사람 | 기계를 돌려놓고 방에 올라가 있다. 언제 끝나는지 알림이 없어 어림짐작으로 내려온다 | 휴대폰 타이머(대략 60분 뒤 알람), 눈대중 |
| A2 | 대기 1번 | 기숙사생 · 다음 순서를 기다리는 사람 | 저녁 피크에 빨래를 들고 내려갔지만 빈 기계가 없어 순서를 기다린다 | 눈대중(잔여시간 표시), 세탁기 위 빨래바구니(=암묵적 예약 표시), 에브리타임(남의 빨래를 뺄 때 미리 알리는 용도) |

**A1과 A2는 같은 사람의 다른 시점이다.** 한 사이클 안에서 A2가 기계를 잡으면 A1이 되고, 건조기 앞에서 다시 A2가 된다. 아래 단계표가 그 한 바퀴다 (S1~S5 = A2 / S6 = A1 / S7 = A2 / S8 = A1).

## 단계 (As-Is → To-Be)

| S | 단계 | 행동(As-Is) | 감정 | 불편 | To-Be 한 줄 |
|---|---|---|---|---|---|
| S1 | 방에서 빨래를 챙겨 출발 | 바구니에 빨래를 담고, 세탁실 상황을 모르는 채로 일단 내려간다 | 막연함 | 자리가 있는지 확인할 방법이 없어 헛걸음이 잦다 | 방에서 실시간 현황을 보고 '세탁기 줄서기' 버튼을 눌러두면 내려갈 필요 자체가 없어진다 |
| S2 | 세탁실 도착 · 빈 기계 확인 | 세탁기 문을 하나씩 열어보거나 잔여시간 표시를 눈으로 훑는다 | 초조함 | 기계마다 남은 시간이 제각각이라 언제 자리가 날지 직접 계산해야 한다 | 잔여시간을 눈으로 계산할 필요 없이, 가장 먼저 끝나는 기계에 FIFO 순서로 자동 배정된다 |
| S3 | 세탁기 위에 빨래를 올려 암묵적 예약 | 돌아가는 세탁기 위에 내 바구니를 올려두고 방으로 올라간다 | 누가 가져갈까 불안함 · "남들도 다 이렇게 하니까 괜찮겠지" 하는 오묘한 자기합리화 | 아무 보장이 없다. 규칙이 어디에도 적혀 있지 않아 급한 사람이나 규칙을 모르는 이용자(유학생 등)에겐 통하지 않고, 순서를 주장할 근거도 없다 | 바구니 대신 '줄서기' 버튼이 순번을 기록으로 남겨, 규칙을 몰라도 화면에 순서가 보인다 |
| S4 | 종료 시간을 어림잡아 다시 내려감 | 대략 30~40분 뒤를 짐작해 다시 내려간다. 타이머를 걸어두기도 한다 | 번거로움 · 계속 신경 쓰임 | 몇 번씩 헛걸음한다. 늦으면 올려둔 예약 빨래가 이미 치워져 있다 | 내 차례가 오면 배정 알림을 받고, 주어진 10분 안에만 내려가면 된다 |
| S5 | 앞사람 빨래를 꺼내고 내 빨래 투입 | 끝난 지 10분이 지나도 안 가져가길래 에브리타임에 "○번 세탁기 빨래 뺄게요"라고 글을 올린 뒤 꺼내고 내 것을 넣었다 | 짜증 · 꺼림칙함 | 공용인데 시간 맞춰 안 내려온 탓에 내가 남의 옷을 만져야 한다. 익명 게시판에 미리 알려야 할 만큼 근거가 없고, 분실·훼손 시비의 소지가 남는다 | 남은 빨래를 꺼내는 일은 여전히 있지만, 앞사람에게 이미 경고 1회가 기록된 뒤라 게시판에 미리 알릴 필요가 없다. 내 빨래를 넣고 QR을 찍으면 사용이 확정된다 |
| S6 | 세탁 종료 후 수거 | 알림이 없어 시간을 재다가 다시 내려가 빨래를 찾는다 | 안도 · 피로 | 늦게 찾으면 나도 남에게 민폐가 된다. 빨래가 옮겨져 있거나 젖은 채 방치된다 | 종료 10분 전 예고 알림을 받고 미리 내려가, 종료 후 3분 안에 수거하고 '다 했어요'를 누른다. 놓치면 경고 1회가 쌓이고(3회 시 3일 이용 제한) 다음 대기자에게 안내가 간다 |
| S7 | 건조기 자리 대기 | 젖은 빨래를 안고 건조기 앞에서 기다리거나, 여기서도 건조기 위에 바구니를 올려둔다 | 답답함 · 조급함 | 건조기가 4대뿐이라 세탁기보다 대기가 훨씬 길다. 젖은 빨래는 방에 두고 오기도 애매해 그 자리에 묶인다 | 세탁 종료 시점에 '건조기 줄서기'를 눌러두면 이어서 FIFO로 배정되고, 젖은 빨래를 안고 기다리지 않아도 된다 |
| S8 | 건조 종료 후 수거 | 건조 시간이 길고 제각각이라 또 시간을 재다 내려간다. 늦으면 남이 꺼내 건조기 위에 올려둔다 | 피로 · 미안함 | 건조기 회전이 한 번 막히면 뒤에 줄 선 사람 전체가 밀린다. 덜 말라 한 번 더 돌려야 하는 경우도 있다 | 세탁기와 같은 규칙(10분 전 예고 → 3분 수거 → 초과 시 경고)으로, 4대뿐인 건조기의 회전율을 지킨다 |

## 흐름
 
### As-Is (지금)
 
```
           ┌───── 빈 기계 있음(한산) ─────┐
           │                              ▼
S1 출발 → S2 확인 → S3 예약 → S4 재방문 → S5 투입 → S6 수거 → S7 건조대기 → S8 건조수거
           ▲                   │                              ▲             │
           └─ 바구니가 치워짐 ─┘                              └─ 덜 말랐음 ─┘
```
 
S1 출발 · S2 빈 기계 확인 · S3 바구니 예약 · S4 어림잡아 재방문 · S5 앞사람 빨래 빼고 투입 · S6 세탁 수거 · S7 건조기 대기(4대뿐, 두 번째 병목) · S8 건조 수거
 
S1 → S2 → S3 → S4 → S5 → S6 → S7 → S8 · 분기: 한산한 시간대에는 S3·S4와 S7의 대기가 사라진다(암묵적 규칙은 저녁 피크에만 발동한다)
 
### To-Be (앱 도입 후)
 
```
                       ┌──────────── 다음 대기자 ─────────────┐
                       ▼                                      │
T1 줄서기 → T2 대기 → T3 배정 → T4 투입 → T5 사용 → T6 기회 → 비어 있음
                       │                             │
                  10분 타이머                   3분 타이머
              (초과 시 순번 소멸)           (초과 시 경고 1회)
```

- **정상** A1이 3분 안에 수거하고 '다 했어요'를 누른다 → 기계가 비어 있음이 되고, 그 순간 A2의 10분이 시작된다
- **조기 종료** 앱 타이머(60분/45분)보다 실제로 빨리 끝났으면 수거 후 '다 했어요'를 눌러 순서를 앞당겨 넘긴다
- **방치** 3분 안에 안 누르면 경고 1회 + 기계 자동 전환. A2는 남은 세탁물을 꺼내고 자기 빨래를 넣는다. 꺼낸 세탁물의 분실은 주인이 감수한다 — 경고 3회면 3일 정지
- **유실** A2가 10분 안에 도착하지 않으면 순번이 소멸하고 그 다음 대기자에게 넘어간다
- **대기자 없음** 3분 기회 시간과 경고는 그대로 적용된다. 넘길 사람이 없으면 기계만 비어 있음이 된다
- **건조기** 45분 기준으로 위 흐름을 그대로 따른다. 알림 시점만 50분 · 35분으로 바뀐다
- **순환** 기계가 비어 있음이 되는 순간 A2가 T3으로 올라가 A1이 되고, 그 사이 새로운 대기자가 T1~T2에 들어와 있다

### T3 진입 조건

- 차례가 오고 **10분 안에 기계를 돌려야 한다.** 도착하지 않으면 그 다음 대기자에게 넘어간다
- **원격 줄서기가 순서를 정하는 유일한 방법이다.** 줄에 없는 사람은 세탁실에 먼저 도착해도 순서를 얻지 못한다 → 앱을 쓰지 않는 이용자 문제는 열린 질문 [?] 참조

### T4 분기 — 내려와서 본 것

| 내려와서 본 것 | 하는 것 | 결과 |
|---|---|---|
| 기계가 비어 있다 | 내 빨래를 넣고 QR 촬영 | T5로 — A2가 A1이 된다 |
| 세탁물이 그대로 있다 | 종료 후 3분이 지났으므로 그냥 꺼낸다 | 주인에게는 경고 1회가 이미 찍혀 있다 |

**'다 했어요'는 세탁물 주인만 누른다.** A2는 이 버튼을 쓰지 않는다. 주인이 3분 안에 안 눌렀으면 경고가 찍히고 기계는 자동으로 '비어 있음'이 되므로, A2는 꺼내고 자기 빨래를 넣은 뒤 QR을 찍으면 된다.

**꺼낸 세탁물의 분실은 주인이 감수한다.** 3분 안에 가져가지 않은 책임이 주인에게 있다는 것을 규칙으로 명시한다.

### 시간 흐름 (세탁기 60분 · 건조기 45분 · 동일 흐름)

| 시점 | A1 (주인) | A2 (대기 1번) |
|---|---|---|
| 종료 10분 전 (세탁 50분 / 건조 35분) | "10분 남았어요" 알림 | [제안] "곧 차례입니다" 예고 알림 — 미채택 |
| 타이머 0 | "다 됐어요" 알림 · **기회 시간 3분 시작** | 대기 — 아직 10분은 시작되지 않는다 |
| 0~3분 사이 '다 했어요' | 경고 없음 · 기계 비어 있음 | **이 순간부터 10분 타이머 시작** |
| 3분 경과 (미수거) | **경고 1회** · 기계 자동 비어 있음 | **이 순간부터 10분 타이머 시작** · 남은 세탁물은 꺼내도 된다 |
| 비어 있음 + 10분 | — | 미도착 시 순번 소멸 하고 즉시 경고 1회 부여 → 그 다음 대기자 |

**A2의 10분은 기계가 '비어 있음'이 된 순간부터 센다.** 그래서 3분 기회 시간은 A2의 10분 안에 포함되지 않는다. A1이 1분 만에 수거하면 A2의 10분도 1분 시점에 시작한다.

**대기자가 없어도 3분 기회 시간과 경고는 동일하게 적용된다.**

## 열린 질문 [?]

- **고정 시간보다 실제 세탁 시간이 더 긴 경우** — 고정 60분 · 45분은 표준 코스보다 길게 잡아 조기 종료를 막았다. 그보다 긴 코스가 존재하면 타이머 0에 경고가 찍히고 A2도 꺼낼 수 없다. 해결 방법은 별도 논의 예정
- **앱을 쓰지 않는 이용자** — As-Is의 핵심 불편이 "규칙을 모르는 사람(유학생)에겐 암묵적 규칙이 안 통한다"였는데, To-Be는 앱 사용자만 줄을 선다. 앱을 안 쓰는 사람이 빈 기계를 그냥 쓰면 FIFO가 통째로 무너진다. 줄서기를 안 하고 사용하는 경우를 막을 방법이 필요하다

### 닫힌 것

- **'다 했어요' 주체** — 세탁물 주인 전용. A2는 누르지 않는다
- **분실 책임** — 3분 안에 꺼내지 않은 주인이 감수한다
- **건조기** — 세탁기와 동일한 흐름 (45분 기준, 예고 35분)
- **A2의 10분 시작 시점** — 기계가 '비어 있음'이 된 순간. 3분 기회 시간은 포함하지 않는다
- **대기자가 없을 때** — 3분 기회 시간과 경고는 동일하게 적용된다
- **순서를 얻는 방법** — 원격 줄서기가 유일하다. 현장 도착 순서는 순번이 되지 않는다
